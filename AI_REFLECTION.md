AI Reflection
Course: CIS 165

AI Usage and Assistance

For this lab, I used AI as a tutor to help me understand how my programs should work. Whenever I got confused or stuck, the AI explained what my code was supposed to do in plain, simple English instead of using coding terms.

During the process, I needed a refresher on how strcmp works to compare two words, so I asked for an explanation on how it reads text letter by letter. Later on while working on the documentation, I also asked how to format tables in Markdown so my test records would look clean and organized in the README file.

Learning and Reflection

Working through this lab helped me understand how computers make decisions step by step. I learned why it is important to check if user inputs make sense right away, like making sure height and weight are greater than zero before doing any math.

I also learned how to handle multiple conditions at once, like mixing two primary colors regardless of which order the user types them in. Breaking down the logic into simple rules made writing and testing the programs much easier.
